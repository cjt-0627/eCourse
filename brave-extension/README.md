# eCourse Brave 扩充功能

这个扩充功能只在本机 `http://localhost:8765` 与清大 eLearn／eeclass 间执行一次性登录交接。它取得的交接码 15 秒后失效且只能使用一次；Cookie 不会交给网页 JavaScript。

## 安装

1. 在 Brave 打开 `brave://extensions`。
2. 开启右上角「开发者模式」。
3. 按「载入未封装项目」。
4. 选择这个资料夹：`/Users/chenjingting/Developer/project/eCourseweb/brave-extension`
5. 回到 eCourse，按 `Command + Shift + R` 重新载入页面。

扩充功能 ID 应为 `amecmikkjicakbcboajnfmbhekmkpahk`。若 Brave 显示其他 ID，请移除该项目后重新载入这个原始资料夹。
